# Set images

Place set artwork or related images in this folder. Files here are served as static assets by Vite/React at the `/sets/<filename>` path.
For new or missing images you add manually, use the `custom/` subfolder so they stay organized.
Name files exactly as the set ID plus the file extension (for example: `68af47c7190c4823de2527df.png`) to keep lookups consistent. If you add both `.png` and `.jfif` versions, keep the same set ID base name for each file.

Keep filenames lowercase-with-dashes when possible to keep URLs predictable.
